# University Management System (UMS)

A web-based University Management System designed to manage and organize different university activities through a single, user-friendly interface.

## Project Overview

The University Management System is a team-based frontend project developed using HTML and CSS.

The system is divided into different modules so that each team member can work independently on a specific part of the application while maintaining a common design and structure.

The project currently focuses on the frontend. JavaScript, backend APIs, and database integration can be added in future development phases.

##  Objectives

- Provide a centralized university management interface.
- Organize university-related information into different modules.
- Create a consistent and user-friendly interface.
- Practice team collaboration using Git and GitHub.
- Build a project structure that can be extended with backend and database functionality.

## Modules

The project contains the following major modules:

### 1. Admin & Dashboard
- Admin Login
- Dashboard
- Summary Cards
- Recent Activities
- Common Navigation and UI

### 2. Student Management
- Student List
- Student Profile
- Add Student
- Search and Filter

### 3. Faculty & Departments
- Faculty Management
- Faculty Profile
- Department Management

### 4. Academic Management
- Courses Management
- Attendance Management
- Examination Management
- Results Management
